:::💿 Sobre o projeto
O Sistema Musical é uma página web criada para apresentar um
formulário de cadastro de músicas. A ideia é reunir informações
importantes de cada faixa em um só lugar, com uma interface organizada e
estilizada.
🎤 O que você encontra por aqui?
- 🎧 Seleção de artista;
- 📝 Campo para título da música;
- 💽 Campo para nome do álbum;
- 🎼 Seleção de gênero musical;
- ▶️ Campo para link do YouTube;
- 🖼️ Seleção de imagem da capa do álbum;
- 📜 Área para adicionar a letra da música;
- 📋 Tabela com exemplo de música cadastrada.
🗂️ Estrutura dos arquivos
Sistema-Musical/
├── cadastro_musica.html  # Estrutura da página de cadastro
├── styles.css            # Estilos e aparência da página
└── README.md             # Apresentação do projeto
🚀 Como visualizar o projeto
1. Baixe ou clone este repositório.
2. Deixe cadastro_musica.html e styles.css na mesma pasta.
3. Abra o arquivo cadastro_musica.html no navegador.
4. Prontinho! 🎉
🛠️ Tecnologias utilizadas
- HTML5 --- estrutura e conteúdo da página.
- CSS3 --- cores, organização, estilos e adaptação para diferentes
  telas.
⚠️ Observação
Este projeto é uma interface front-end. O formulário ainda não possui
integração com banco de dados ou programação de servidor para salvar os
cadastros. Portanto, preencher os campos não significa que as
informações serão armazenadas.
💖 Feito para aprender!
Este projeto faz parte de uma atividade de desenvolvimento web e reúne
conceitos de estruturação com HTML e estilização com CSS.
